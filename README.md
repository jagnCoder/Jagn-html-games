# 🕹️ Mini Arcade

A lightweight collection of web-based mini-games built with **HTML**, **JavaScript**, and styled using **Tailwind CSS**. Test your reflexes and your visual acuity right from your browser!

🌐 **[Play Live on Netlify](https://color-guessing-game-by-jagn.netlify.app/)**

---

## 🎮 Included Games

### 1. ⚡ Reaction Timer
* **Goal:** Test your reflexes by clicking the screen the exact moment it turns green.
* **Features:** Millisecond-precision timing to track your fastest scores.

### 2. 🎨 Color Guess Challenge
* **Goal:** Guess the correct hex code for a displayed color.
* **Features:** A true test of your color-imagination, visual acuity, and memory.

---

## 🛠️ Built With

* **HTML5** - Structure and layout
* **Tailwind CSS** - Modern, responsive styling
* **JavaScript** - Game logic and interactivity

## 🚀 Getting Started Locally

To run this project locally on your machine, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/jagnCoder/Jagn-html-games.git](https://github.com/jagnCoder/Jagn-html-games.git)

```

2. **Navigate to the project directory:**
```bash
cd Jagn-html-games

```


3. **Open the project:**
* Open `index.html` in your favorite web browser, or use a live server extension (like the one in VS Code) to view the arcade menu.
